🧪 Developer: test pre-releases›

Pre-releases (on GitHub) are test versions before the finished version. Normal updates never show them – here you can search for them on purpose.

⚠️
  • Pre-releases may contain bugs. Features may still change, be unfinished or be removed again.
  • The update applies to the whole server: all families and all devices will use the pre-release afterwards.
  • Not recommended if you rely on pinn. in everyday life – for example for appointments, reminders or emergency cards.
  • pinn. is unavailable for a few minutes during the installation.
🛟Your data is not lost: before the installation pinn. automatically creates a backup (“Before an update”). With “Restore” → “Everything” you can go back to the previous state at any time. As soon as the finished version is out, it is offered as a normal update.
🐞If you notice something, please report it on GitHub – with version, device and what you were doing. Notes from the error log help with that.Report a bug ↗
