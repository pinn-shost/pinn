---

pinn.は、家庭を回すためのすべてをまとめたアプリです。共有カレンダー、今週の献立、買い物リスト、ごみ出しの担当、お小遣い、3月に解約しなければならない保険など。**あなた自身のNAS**でDockerを使って動き、家族のすべてのiPhone、iPad、Androidスマートフォンにネイティブアプリのようにインストールできます。

クラウドアカウントは不要。定期購読もありません。広告も追跡もありません。家族のデータは家の外に出ません。

## pinn.でできること

| | |
|---|---|
| 📅 **カレンダー** | 人ごとのiCloudとGoogleカレンダーを、非公開にも家族との共有にもできます。祝日、学校の休み、ごみ回収日、連絡先の誕生日が自動で表示されます。 |
| 🍝 **食事とレシピ** | 一週間を計画し、材料をそのまま買い物リストへ。テキスト、PDF、写真、リンクからレシピを取り込めます（AIの利用は任意）。お気に入りのレシピを同じサーバー上のほかの家族と共有できます。 |
| 🛒 **リスト** | お店ごとの買い物リスト、在庫が減るとリストを補充するストック、テンプレートからの持ち物リスト（旅行、入院バッグ、パーティー）、ギフトリストとほしいものリスト（贈られる本人には見えない「誰が何を贈る」プランナー付き）。 |
| ✅ **タスクと家事** | プッシュのリマインダー付きタスク、掃除計画、ごみ箱。さらに、時間帯に合うことだけを表示するアニメーション付きの日課を備えた子どものページ。 |
| 💶 **家計** | 共有または個人の財布、家計の予算、ETFや株式を扱う貯蓄と証券口座、お小遣い、定期的な支払い、解約リマインダー付きの契約。ルームシェアでは費用を分け合い、だれがだれにいくら支払うかを確認できます。 |
| 📄 **書類と乗り物** | レシートと保証、期限リマインダー付きの身分証。車と自転車の車検日、タイヤ交換、燃費、総費用。 |
| 🏡 **住まい** | 借主、所有者、貸主向け：賃貸借または売買契約書、ローン、写真付きの不具合、請求書、リフォーム計画、予測つきの検針、鍵、貸している部屋・家・ガレージの家賃収入。雨が降った日を把握している水やり計画つきの庭と植物。 |
| 📍 **家族と位置情報** | pinn.から直接、一度だけ、または選んだ時間だけ位置情報を共有できます。無料アプリのTraccar Clientを使えばバックグラウンドでも共有できます（pinn.に直接送信、追加サーバー不要）。さらに「帰宅中」モード、位置と緊急番号つきのSOSアラート、緊急カード、場所への到着通知。 |
| 🎒 **学校と保育園** | 子どもごとに：時間割（入力するか、写真を撮るとAIが入力）、送り迎え、子どものページの宿題、期限がリマインダーになる保護者向けのお便り、カレンダーに直接表示される休園・休校日。 |
| 🐾 **ペット** | 犬、猫、うさぎなどのプロフィール。チェックできる食事の時間、散歩、「だれの番？」の当番表、プッシュのリマインダー付きの予防接種と駆虫、体重グラフ、獣医と救急動物病院、共有できるペットシッター用シート、印刷できる「迷子」ポスター、自動給餌器の補充リマインダー。 |
| 🌦️ **天気と休暇** | 天気をタップすると（スマートフォンではタイル、iPadとパソコンでは日付と時刻の横の上部）、14日分と各日の詳細を確認できます。目的地と日程を入れた持ち物リストには休暇中の天気（予報または平年値）が表示され、持っていくものを提案します。 |
| 🏠 **スマートホーム** | タスクからAppleショートカットやHome Assistantのアクションを開始：家事の期日にロボット掃除機がキッチンを掃除し、ロボット芝刈り機と水やりは庭の計画に従い、自動給餌器は空になりそうなときに知らせます。 |
| 🎙️ **音声操作** | 「Hey Siri、pinn」：買い物リストに追加、読み上げ、タスクの作成、今日の予定の確認。Androidでも使えます。 |
| 💬 **チャット** | 家族チャットと個別チャット。エンドツーエンド暗号化、プッシュ、既読チェック、返信に対応。 |
| 🔔 **通知** | iPhone、iPad、Androidに届く個人向けのプッシュメッセージと、家族内のあらゆる変更を集めるベル。 |
| 🧩 **そのほか** | 動かせるメモ付きの家族の掲示板、全体検索、自動同期付きのオフラインモード、ダークモード、プロフィールPIN付きのiPadダッシュボード、ゲストアカウント、チャイルドロック。 |

pinn.は **🇬🇧 English、🇩🇪 Deutsch、🇪🇸 Español、🇫🇷 Français、🇮🇹 Italiano、🇧🇷 Português、🇨🇳 中文、🇯🇵 日本語、🇰🇷 한국어、🇷🇺 Русский、🇳🇱 Nederlands、🇹🇷 Türkçe、🇵🇱 Polski、🇺🇦 Українська** に対応し、通貨と緊急番号をお住まいの地域に合わせ、**家族**と**ルームシェア**の表現を切り替えます。1台のサーバーで複数の家族を運用でき、それぞれに管理者を置けます。

## 1.154.0の新機能

**カレンダーアドレスのセキュリティ修正**

- 修正：カレンダーのアドレスを検証するようになりました。iCloud や Google で予定を削除・変更・取得するとき、サーバーは家族カレンダーのログイン情報を使い、送信先は Apple と Google のサーバーだけです。以前は、ログイン済みのプロフィールが細工したリクエストでログイン情報を任意のサーバーへ送らせることができました。すでに動作しているカレンダーへの影響はありません。
- 変更: `pb_hooks/calendar-sync.js`, `js/versionslog.js`, `js/sprachen.js`, `i18n/versionslog.en.js`, `src/`, `index.html`, README.

## 1.153.0の新機能

**Home Assistant のセキュリティ表示**

- 新機能：**セキュリティ** – 家族の管理者は 設定 → セキュリティ で Home Assistant のデバイスを名前付きグループにまとめられます：窓とドア、ドアロック、カメラ、ガレージとシャッター、煙・水漏れ検知器、警報システム、人感センサー。ファミリーダッシュボードの下部にバーが表示され（例：「すべて閉まっています」「キッチンの窓 が開いています」「1 台のカメラがオンです」、警報時は赤）、概要には「セキュリティ」タイルが加わり、大人は開いているドアロックを施錠できます（解錠は不可）。任意の**夜のチェック**：指定時刻にまだ開いている・未施錠・警報解除のものがあれば、管理者全員にプッシュ通知が届きます。前提：設定 → スマートホーム で Home Assistant が接続されていること。
- 修正：ダークモードでタスク名の下のボタン（スマートホーム開始、メーター読み取り …）が青地に青だった問題 – 金色になりました。

## 1.152.1の新機能

**バックアップの復元が再び使えるように**

- 修正：バックアップの復元（設定 → システム → バックアップと更新）が、データのみでもすべてでも、必ず「バックアップを確認」で止まっていました。直前に行う現在の状態のバックアップが古いバックアップを整理する際、選んだバックアップの名前を上書きしてしまい、見つからなくなっていたためです。失敗のたびに「復元の前」のバックアップが残りますが、害はなく自動で整理されます（最新3件を保持）。更新で `pinn-wartung.sh` が新しくなり、コンテナ「wartung」は自動で再起動します。
- Portainer スタック：バックアップが本当に使えるようになりました。1.151.0 の一部がリポジトリに欠けていたため、スタックのサービス「wartung」は起動できませんでした。現在はイメージにバックアップスクリプトが入っていて、スタックの pinn コンテナを自動で見つけます。夜間バックアップ、「今すぐバックアップ」「復元」（データと設定）はスクリプト版と同じように使えます。更新は引き続き Portainer で行います。更新後は Portainer で「Update the stack」を「Re-pull image and redeploy」オンで実行してください。
- 変更: `pinn-wartung.sh`, `docker/Dockerfile`, `.github/workflows/image.yml`, `pb_hooks/pinn-system.js`, `js/sicherungen.js`, `js/serverzugriff.js`, `i18n/`, `js/versionslog.js`, `js/sprachen.js`, `src/`, `index.html`.

## インストール

1. [最新リリース](https://github.com/pinn-shost/pinn/releases/latest)のZIPをダウンロードして展開します。
2. NASにフォルダを作成し（例：`/volume1/docker/Pocketbase`）、展開したフォルダ（例：`pinn-1.154.0`または`pinn-main`）をそのまま入れます。
3. SSHでログインして次を実行します：
   ```sh
   cd /volume1/docker/Pocketbase && sudo sh pinn-*/pinn-setup.sh
   ```
   スクリプトがすべてのファイルを所定の場所にコピーし、PDF取り込みと写真の文字認識に必要なライブラリをダウンロードして、pinn.を起動します。
4. `http://<NASのIP>:8090`を開き、**メイン管理者としてログイン** → パスワード`Admin` → 自分のパスワードを設定します。
5. **セットアップアシスタント**が、HTTPS、WireGuardまたはTailscaleでのリモートアクセス、Google、AI、位置情報、Home Assistantといった残りの設定を、14の言語で順番に案内します。
6. 各スマートフォンでHTTPSアドレスからpinn.を開き、ホーム画面に追加します：
   - **iPhone/iPad（Safari）：** 共有 → *ホーム画面に追加*（通知にはiOS 16.4以降が必要）
   - **Android（Chrome）：** 設定 → 通知 → *pinn.をアプリとしてインストール*、またはChromeのメニュー ⋮ → *アプリをインストール*

   そのあと、各デバイスで**設定 → 通知 → このデバイスで有効にする**から通知をオンにします。

**アップデート：**新しいZIPをダウンロードし、展開したフォルダを同じフォルダに入れて、もう一度`sudo sh pinn-*/pinn-setup.sh`を実行します。置き換えられたファイルは`_alt/`に残り、データには手を付けません。

**バックアップ**は毎晩`./backups`に作成され、14日間保存されます。

<a id="privacy"></a>

### Portainer スタック（スクリプト不要）

Portainer のほうがお好みですか？ SSH もセットアップスクリプトも不要です。

1. Portainer で **Stacks → Add stack** を開き、名前を `pinn` にして **Web editor** を選びます。
2. [`docker/docker-compose.portainer.yaml`](docker/docker-compose.portainer.yaml) の内容を貼り付けます。
3. 任意：**Environment variables** でポート（`PINN_PORT`、既定は 8090）を変更するか、バージョンを固定します（`PINN_IMAGE_TAG`、例：`1.151.0`）。**Deploy the stack** をクリックします。
4. `http://<NASのIP>:8090` を開き、**メイン管理者としてログイン** → 設定アシスタントへ（上の手順 4～6 と同じ）。

イメージは `ghcr.io/pinn-shost/pinn`（amd64 と arm64）から出来合いで提供されます。データはボリュームに保存されるのでフォルダは不要です。スタックは固定のコンテナ名を使わないため、既存のコンテナと衝突しません。NAS で Tailscale がすでに動いている場合は `tailscale` ブロックを削除し、独自の HTTPS アドレスやリバースプロキシを使う場合は `caddy` と `duckdns` も削除してください。

**更新：** Stack → Editor → *Update the stack* で *Re-pull image and redeploy* をオンにします。**バックアップ：** スタックの `wartung` ブロックが毎晩バックアップを作成し（7 日分 + 4 週分を保持）、pinn. →設定→システムの「今すぐバックアップ」「復元」ボタンの裏側で動きます。バックアップはボリューム `backups` に保存されます（`PINN_BACKUP_DIR` を設定すると NAS のフォルダ、例：`/volume1/docker/pinn-backups`）。復元時に pinn. を一時停止するため Docker へのアクセスが必要です。ボリュームを自分でバックアップする場合はこのブロックを削除してください。アップデートはボタンではなく Portainer で行います。任意（ファイル末尾にコメントアウト、`#` を外すと有効）：Traccar（SIM 付き GPS トラッカー）と Home Assistant への迂回。スマートフォンには不要です。

### 自分のリバースプロキシでインターネットからアクセス

家族が Tailscale を使いたくない場合は、pinn. をリバースプロキシの後ろに置きます。プロキシがインターネットからのリクエストを受け取り、自分のドメインで HTTPS を提供し、pinn. へ転送します。

1. プロキシの転送先を `http://<NAS-IP>:8090` にします（Portainer スタックではポート `PINN_PORT`）。ライブ更新は通常の HTTP を使うため websocket は不要です。レスポンスのバッファリングだけはオンにしないでください。最大 70 MB のアップロードを許可します（チャットの動画）。
   - **Nginx Proxy Manager：** *Hosts → Proxy Hosts → Add*：自分のドメイン、スキーム `http`、NAS の IP、ポート `8090`。*SSL* タブで新しい証明書、*Force SSL* をオン。
   - **Cloudflare Tunnel：** ポート開放は不要 – *Public hostname* → サービス `http://<NAS-IP>:8090`。
   - **Traefik、Caddy など：** 自分のドメイン用に `http://<NAS-IP>:8090` へ転送するルーター/サイトを作成。
2. 各スマートフォンで `https://<domain>` を開いてサインインし、ホーム画面にもう一度追加して通知を再度オンにします（アプリはアドレスごとに別扱いです）。
3. Google カレンダー（任意）：Google Cloud コンソールで `https://<domain>/api/pinn/google/callback` を承認済みのリダイレクト URI に追加します。

pinn. が自動で行うこと：プロキシが渡す訪問者アドレス（`X-Forwarded-For`）は、リクエストが自宅ネットワーク、Docker ネットワーク、Tailscale から来た場合にのみ信用します。これによりパスワード誤り後のロックを回避できません。インターネットからは PocketBase の管理画面（`/_/`）がブロックされ、初期パスワード `Admin` は使えません。プロキシが別の場所にある場合（レンタルサーバー、またはプロキシの前に Cloudflare のオレンジの雲）は、`PINN_PROXY_NETZE` を設定してください（`.env` またはスタックの環境変数）。例：`privat, cloudflare` や `privat, 203.0.113.5`。

**重要：** pinn. はインターネット全体からアクセス可能になります。各プロフィールに長い固有のパスワードを設定し、プロキシを最新に保ち、ルーターでポート 8090 を直接開放しないでください。必ず HTTPS 付きのプロキシ経由にします。

## プライバシー

pinn.は、クラウドサービスには決して預けたくないデータのために作られました。銀行の取引明細、健康に関する書類、子どもたちの居場所などです。そのため：

- **すべてのデータはあなたのNASに**、1つのPocketBaseデータベースとして保存されます。pinn.のサーバーはなく、テレメトリもありません。
- **外部サーバーのスクリプトは使いません。**すべてのコードとライブラリはあなたのNASから配信されます。
- **プッシュ通知に内容は含まれません。**Apple、Google、Mozillaは空の起動シグナルを届けるだけで、デバイスがあなたのNASからメッセージを取得します。
- **iCloudとGoogleのパスワード**は、ロックされたコレクションに暗号化して保存されます。
- **インターネットからは接続できません。**リモートアクセスはあなた自身のVPN経由です。

pinn.が外部サービスに接続するのは、それを必要とする機能のときだけです：

## FAQ

<details>
<summary><b>ルーターのポートを開ける必要はありますか？</b></summary>
<br>
いいえ。HTTPS証明書はDNS確認で発行され、リモートアクセスはVPN経由です。FRITZ!BoxではWireGuard、そのほかのルーターではTailscaleを使います。
</details>

<details>
<summary><b>NASがなくても使えますか？</b></summary>
<br>
Dockerが動く常時稼働のマシンなら使えます。ミニPC、Raspberry Pi 4/5、Linuxサーバーなどです。
</details>

<details>
<summary><b>pinn.はApp Storeの「本物」のアプリですか？</b></summary>
<br>
pinn.はホーム画面に追加するWebアプリです。追加するとネイティブアプリのように全画面で開き、オフラインでも動作し、未完了のタスクをバッジで表示し、プッシュ通知も受け取れます。アプリストアは不要です。
</details>

<details>
<summary><b>1つのインストールを複数の家族で使えますか？</b></summary>
<br>
はい。メイン管理者が家族を作成し、各家族に専用の管理者、カレンダー、データが用意されます。レシピは家族間で任意に共有できます。
</details>

<details>
<summary><b>子どもはどうなりますか？</b></summary>
<br>
チャイルドロックのあるプロフィールは自分のタスクだけが見え、何も削除や変更ができません。家計、書類、乗り物は非表示のままです。小さな子どもには、毎日の日課を載せた楽しい専用ページがあります。
</details>

<details>
<summary><b>費用はかかりますか？</b></summary>
<br>
かかりません。pinn.は無料で、MITライセンスのオープンソースです。Gemini AIなどのオプションサービスには無料枠があります。
</details>

## 参加する

不具合の報告、アイデア、翻訳を心から歓迎します。[CONTRIBUTING.md](.github/CONTRIBUTING.md)をご覧ください。セキュリティの問題は、[SECURITY.md](.github/SECURITY.md)の説明に従って非公開で報告してください。プルリクエストの前に`node .github/scripts/check-all.js`を実行してください。同じチェックがGitHubでも自動的に実行されます。
