# pinn. 1.31.1 – Fixes

## 🇬🇧 English
- Barcode scanner: no more dark veil over the camera image on iPhone – only the area around the frame is darkened. The torch button is clearly visible (white, yellow when on) and shows a hint if the device doesn't allow the torch. Exposure stays on automatic where the device supports it.
- Settings on phones: the opened section scrolls up so its heading sits at the top edge of the screen.
- Finance: the period bar is aligned properly – on phones Week/Month/Year and "Today" in the first row, ‹ period › across the full width below.

**Update:** `pb_public/index.html` and `pb_public/lang/en.js`, `fr.js`, `es.js`. No server changes.
