      Pre-releases (on GitHub) are test versions before the finished version. Normal updates never show them – here you can search for them on purpose.

      ⚠️
      • Pre-releases may contain bugs. Features may still change, be unfinished or be removed again.
      • The update applies to the whole server: all families and all devices will use the pre-release afterwards.
      • Not recommended if you rely on pinn. in everyday life – for example for appointments, reminders or emergency cards.
      • pinn. is unavailable for a few minutes during the installation.
      🛟Your data is not lost: before the installation pinn. automatically creates a backup (“Before an update”). With “Restore” → “Everything” you can go back to the previous state at any time. As soon as the finished version is out, it is offered as a normal update.

        Devices
        
        
      
        
      
        
      
        
        
        How to set it up
        
        
        1. Create a device and choose whether it runs via Apple Shortcuts or Home Assistant.
        2. Set up actions (shortcut name or entity from Home Assistant) – “▶ Test” tries them right away. With a duration or status entity, actions of the same device run one after another.
        3. On the Household page, select the actions in a cleaning task or a bin.
        Home Assistant works on all devices (including Android) and doesn't need a phone for the automation.
        
      
        
    
        

    
        
      
        
        
        Automation
        
        
      
        
      
        
      
        
        
        Buttons with shortcuts
        
        
        In the Shortcuts app, create one shortcut per action, e.g. with the Home action “Run Scene” or your robot vacuum's action, and enter the name exactly like that for the device. pinn. passes the room name as input to the shortcut – so a single shortcut can handle all rooms. Works on iPhone, iPad and Mac.
        
      
        
    
        

    
        
      
        
    
        

    
        
      
    
        
  
        

        



        
  
        
    
        New device
        
    
    
        
    
    
        
    
    
    
    
        
    
        
    
        
      
      
    
        
    
        
    
        Name of the action as it appears on the task, next to it the approximate duration in minutes. With a duration, the device is occupied for that long – further actions of the same device only start afterwards (e.g. first vacuum the living room, then mop the kitchen). Better plan a few minutes of buffer, including the return trip to the station. With Home Assistant and a status entity, the device's real state also counts.
